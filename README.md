# World Happiness Score Analysis

**GitHub Link:** [World Happiness Scores](https://github.com/aschrameck/World-Happiness-Scores)

---

## Project Overview

This project analyzes global happiness data from the Gallup World Poll to explore relationships between happiness scores, GDP per capita, life expectancy, and other socio-economic factors.

Key objectives include:

* Cleaning and preprocessing global survey data.
* Performing statistical analysis to identify correlations and patterns.
* Visualizing trends in happiness, wealth, and health metrics across countries.

---

## Prerequisites

* **R** (version 4.x or higher recommended)
* R packages: `tidyverse`, `ggplot2`, `dplyr`, `readr`
* Optional: RStudio for interactive development

---

## Setup Instructions

### Step 1: Clone the Repository

```bash
git clone https://github.com/aschrameck/World-Happiness-Scores.git
cd World-Happiness-Scores
```

### Step 2: Install Required R Packages

```r
install.packages(c('tidyverse', 'ggplot2', 'dplyr', 'readr'))
```

### Step 3: Run Analysis

* Load the main R script (e.g., `happiness_analysis.R`) in R or RStudio.
